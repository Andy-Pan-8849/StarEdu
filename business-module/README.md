# Business Module (placeholder)

The traditional enterprise back office, modeled on the feature set of an open-source competitor and rebuilt with TypeScript: Next.js 15, Tailwind, shadcn/ui and NestJS.

Status: **not started.** This module comes after the AI module. The scope (which modules of the open-source competitor to include) has not been discussed yet.

The synthetic company data in `../ai-module/sample-data/structured/` (campuses, employees, expense claims, support tickets, students, assignments, submissions) is meant to seed this module as well, so both systems describe the same company.
