# Experiment matrix (2026-11-04 05:04 UTC)

Models: embedding `text-embedding-3-small`, derive `openai/gpt-6-luna`. Estimated cost before the run about US$0.017.

Each experiment re-ingests the sample documents into a temporary database (the development database is unaffected) and, for all answerable questions with a source document, searches in the three modes keyword / vector / hybrid (without rerank, which is tested in the full evaluation). hit@k: the share where the source document is among the top k results; MRR: the mean of the reciprocal rank of the source document.

## Not in this matrix

- **Rerank implementation**: there is only the LLM listwise rerank and no dedicated rerank interface is connected, so there is nothing to compare.
- **Keyword ranking `ts_rank_cd` versus the BM25 extension**: the BM25 extension was neither installed nor verified, and is not brought in in phase 1.
- Derived content only strengthens the **vector** side (it is added to the embedded text) and the keyword side does not use it, so it has no effect on the keyword mode.
