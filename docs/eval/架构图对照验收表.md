## 四、结论

- **第一阶段需求清单 A–H 没有真正的缺项**；有五处是打了折扣的（上下文只截断不摘要、显式拒绝在认证层、Loki、lite、20% 人工抽查），上面都已标明。
- **图上有、但需求清单没有、也没规划的**：PII 脱敏与输出端护栏、Jailbreak 检测、Analytics 与 Web Search Agent、MCP Resources、Local vLLM、Redis 的缓存与黑名单、Vault 与 Sentry、边缘反向代理与 WAF。是否纳入第二阶段由你决定。
- **做法与图不同、且是有意决定的**：Postgres 队列代替 Kafka、Postgres 全文代替 Elasticsearch、视图代替 RLS、LLM 重排代替 Cohere、固定回复代替 chit-chat 的模型调用、会话状态存表代替 checkpointer。
- 下一步做什么待决定，见本表第三节的"建议"一栏。
