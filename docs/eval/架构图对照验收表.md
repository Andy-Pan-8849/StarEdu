## 结论

- **第一阶段需求清单 A–H 没有真正的缺项**；有 5 处打了折扣：上下文只截断不摘要、显式拒绝在认证层、Loki、lite（k3s）、20% 人工抽查。
- **做法和图不同、但是有意决定的**：Postgres 队列代替 Kafka、Postgres 全文代替 Elasticsearch、视图代替 RLS、LLM 重排代替 Cohere、会话状态存表代替 checkpointer、固定回复代替 chit-chat 的模型调用、原文由 api 转发代替预签名 URL。
- **图上有、需求里没有、也没规划的**（需要你决定要不要纳入）：输出端护栏与 PII 脱敏、Jailbreak 检测、MCP Resources、Analytics 与 Web Search Agent、LLM fallback、Redis 的缓存与黑名单、Local vLLM、Vault 与 Sentry。
- **配了但我没验证的**：Anthropic 模型路径。
- **正式的 P1 四项**：流式输出（建议补上）、成本与延迟统计（建议补上）、Memory（放一放）、写操作确认（放一放，等企业后台）。
