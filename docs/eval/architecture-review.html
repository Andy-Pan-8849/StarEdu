Architecture diagram review

Every cell of the reference architecture diagram (interview_arch_traditional_plus_ai_v2.png) that concerns the AI part is compared with what v0.1.0 actually delivers, with a status and a reason for each cell. 2026-11-04.

Phase 1 list A to H has no real gaps; 5 items were scaled back: the context is only truncated and not summarised, explicit denial is in the authentication layer, Loki, lite, the 20% human spot check.
Done differently from the diagram, by deliberate decision: a Postgres queue instead of Kafka, Postgres full text instead of Elasticsearch, views instead of RLS, LLM rerank instead of Cohere, conversation state in a table instead of a checkpointer.
On the diagram, but not in the requirements and not planned: output guardrails and PII masking, jailbreak detection, MCP Resources, Analytics and Web Search, fallback, Redis caching. The ones marked "Needs your decision" in red are these.
